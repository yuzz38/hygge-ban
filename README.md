# Hygge Barn — лендинг

Одностраничный сайт гостевых домов **Hygge Barn** (посёлок Бурдугуз, Иркутский район): два дома-барна в сосновом лесу у Ангары.

## Состав

```
index.html            — страница
css/style.css         — стили
js/main.js            — скрипты (без библиотек)
img/                  — оптимизированные фото: WebP + JPEG-фолбэк, 600 и 1200 px
video/hygge-barn.mp4  — фоновое видео без звука (H.264, faststart), poster.jpg
robots.txt, sitemap.xml, llms.txt  — SEO / GEO
site.webmanifest, favicon.ico, favicon-32.png, apple-touch-icon.png, icon-192/512.png
.htaccess             — сжатие и кэширование для Apache
```

## Блоки

1. Первый экран: видео в окне-силуэте дома (форма из логотипа) с гирляндой.
2. «Хюгге — это когда…»: текст со встроенными фото.
3. Поводы: вдвоём, семьёй, компанией, праздник, перезагрузка, наедине с собой. Для каждого показан сценарий дня.
4. Два дома с галереей, характеристиками и планировкой по этажам.
5. Переключатель «Лето / Зима»: меняются фото обоих домов и текст, зимой идёт снег. Сезон выбирается автоматически по текущему месяцу.
6. Территория: сауна, костёр и мангал, Ангара, всего два дома, удобства.
7. «Продумано до мелочей».
8. Условия и частые вопросы.
9. Слайдер отзывов: свайп, перетаскивание мышью, стрелки, клавиатура.
10. Бронирование, контакты, Яндекс Карта и ссылки на маршрут.

Также: бургер-меню на мобильных, кнопка «Выбрать даты», закреплённая внизу экрана, лайтбокс для фото, разметка Schema.org (LodgingBusiness + FAQPage), Open Graph, geo-метатеги.

## Перед публикацией

- Замените домен `https://hyggebarn.ru/` на реальный в `index.html` (canonical, og:url, og:image, JSON-LD), `robots.txt`, `sitemap.xml`.
- Если появится телефон, добавьте его в блок контактов и в `telephone` в JSON-LD.
- Сайт статический, работает на любом хостинге: просто загрузите содержимое папки в корень.

Поддержка: Safari iOS 13+, Chrome/Android, Firefox, Edge, Яндекс Браузер. Учтены safe-area для iPhone, `prefers-reduced-motion` и режим экономии трафика (видео не запускается).
